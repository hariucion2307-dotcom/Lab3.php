Теоретическая часть
2.1. Управляющие конструкции в PHP
Управляющие конструкции - это элементы языка программирования, которые определяют порядок выполнения инструкций программы.
Они позволяют выполнять определённые действия в зависимости от условий, многократно повторять команды и управлять последовательностью выполнения программы.
К основным управляющим конструкциям PHP относятся:
•	условные операторы if, elseif, else;
•	оператор выбора switch;
•	циклы for, while, do-while, foreach;
•	операторы управления циклом break и continue.
•	Условные конструкции используются для принятия решений, а циклы — для повторного выполнения определённых операций.
2.2. Функция date()
•	Функция date() предназначена для получения и форматирования текущей даты и времени. 
2.3. Условные конструкции
Условная конструкция if позволяет выполнить блок команд, если заданное условие истинно.
2.4. Цикл for
Цикл for используется для многократного выполнения блока команд. Он особенно удобен, когда количество повторений известно заранее или определяется счётчиком.
Цикл содержит три части:
1.	Начальное значение счётчика.
2.	Условие продолжения выполнения цикла.
3.	Изменение счётчика после каждой итерации.
2.5. Циклы while и do-while
Цикл while проверяет условие перед выполнением тела цикла. Если условие изначально ложно, тело цикла не выполняется.
Цикл do-while сначала выполняет тело цикла, а затем проверяет условие. Поэтому тело do-while выполняется минимум один раз, даже если условие изначально ложно.

Объяснение программы
В начале программы переменным $a и $b присваивается начальное значение 0.
Заголовок цикла:
for ($i = 0; $i <= 5; $i++)
означает, что:
•	счётчик $i начинается с 0;

Выражение $a += 10 увеличивает значение переменной $a на 10. Оно эквивалентно записи $a = $a + 10.

Команда echo выводит промежуточные значения переменных после каждого изменения. После завершения цикла выводится итоговое значение переменных.
Поскольку счётчик принимает значения от 0 до 5 включительно, цикл выполняется шесть раз.

Контрольные вопросы
1.В чём разница между циклами for, while и do-while? В каких случаях лучше использовать каждый из них?  
Циклы for, while и do-while предназначены для многократного выполнения блока команд, однако отличаются способом организации и моментом проверки условия.
             Цикл for
          Цикл for обычно применяется в ситуациях, когда количество повторений известно         заранее или определяется счётчиком. 
Цикл for удобно использовать для:
•	перебора числовых диапазонов;
•	обработки элементов массивов по индексам;
•	выполнения заданного количества повторений;
•	повторения операций с известным числом шагов.
Цикл while
Цикл while используется, когда количество повторений заранее неизвестно и выполнение зависит от некоторого условия. 
Цикл повторяет блок кода, пока выполняется условие. while проверяет условие до тела, поэтому при ложном условии тело не выполнится ни разу.
Цикл do-while
Цикл do-while сначала выполняет тело цикла, а затем проверяет условие. Проверяет условие после тела, поэтому тело выполняется минимум один раз. Цикл do-while удобно использовать, когда действие должно произойти хотя бы один раз, например при отображении меню программы или запросе пользовательского ввода с последующей проверкой.
Главное различие: в циклах for и while условие проверяется до выполнения тела, а в do-while — после выполнения тела.
Вопрос 2. Как работает тернарный оператор ? : в PHP?
Тернарный оператор - это сокращённая форма условного выражения if-else. Он позволяет выбрать одно из двух значений в зависимости от результата проверки условия.
Если условие истинно, возвращается значение, расположенное после знака ?. Если условие ложно, возвращается значение после двоеточия :.
Таким образом, тернарный оператор полезен для коротких условий, когда необходимо выбрать одно из двух значений. Для сложных условий и нескольких действий обычно удобнее использовать обычную конструкцию if-else. 
Вопрос 3. Что произойдёт, если в do-while поставить условие, которое изначально ложно? 
Если условие цикла do-while изначально ложно, тело цикла всё равно выполнится один раз. Это происходит потому, что проверка условия осуществляется после выполнения команд внутри блока do. 
Вывод: цикл do-while гарантирует минимум одно выполнение тела цикла, тогда как while может не выполниться ни разу.
